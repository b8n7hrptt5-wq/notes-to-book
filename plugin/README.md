# notes-to-book · Obsidian 插件

把一摞笔记排成一本 A4 的书：封面、目录、章首页、页眉页脚、页码、跨页表格自动拆分，导出 PDF，并在导出后**自动核对成品里有没有丢内容**。

这是给不敲命令行的人用的版本。仓库根目录那套 `bookgen.py` 是同一件事的命令行实现，两者互不依赖。

---

## 安装（3 步，不用命令行）

1. **找到你的库文件夹**
   Obsidian 左下角齿轮 → 「关于」→ 库文件夹路径。或者右键库名 → 「在访达中显示」。

2. **把插件拷进去**
   把本目录（`plugin`）整个复制到：

   ```
   <你的库>/.obsidian/plugins/notes-to-book/
   ```

   注意：文件夹名必须是 `notes-to-book`（和 `manifest.json` 里的 `id` 一致），
   并且这三个文件要直接躺在这个文件夹里：

   ```
   <你的库>/.obsidian/plugins/notes-to-book/
     main.js
     manifest.json
     styles.css
   ```

   如果 `.obsidian` 是隐藏文件夹，在访达里按 `⌘ ⇧ .` 就能看见。

3. **在 Obsidian 里打开它**
   设置 → 第三方插件 → 关掉「安全模式」→ 点刷新 → 在列表里打开 **Notes to Book**。
   装好后左侧会出现一个书本图标，也可以 `⌘P` 搜「排版当前笔记」。

> 只想先用示例试一下：把 `samples/` 里的 `稿件-通用示例.md` 和 `项目笔记/`、`assets/` 拖进任意库，再按下面三步走。

---

## 三步出书

1. `⌘P` →「排版当前笔记」（或点左侧书本图标）——会打开排版窗口，当前这篇就是第一篇。
2. 顶栏「**选稿**」把其余笔记加进来。每篇笔记有个「角色」：
   - `chapter`：独立成章，配一张章首页
   - `section`：归到上一章里当小节
3. 顶栏选模板 →「**导出 PDF**」。导出后会自动弹「导出后核对」。

顶栏从左到右：书名 · 模板 · 选稿 · 全文设置 · 核对成品 · 导出 PDF。窗口右侧是逐篇清单，点页面上的任意一块可以在右边改它的排版。

## 十套模板

| 模板 | 适合 | 一眼能认出来的地方 |
| --- | --- | --- |
| 文章 article | 单篇长文、随笔 | 单栏、首行缩进两字 |
| 正式报告 report | 汇报、复盘 | 标题居中，二级标题带竖条和细线 |
| 会议纪要 minutes | 会议记录 | 紧凑、要点密集 |
| 交接资料 handover | 交接文档 | 信息密度高 |
| 课程讲义 lecture | 教材、课堂讲义 | 章首页有大号码 |
| 技术手册 manual | 说明文档、API 手册 | 代码块突出 |
| 研究汇编 anthology | 多篇合集 | 偏书版式 |
| 图文作品集 portfolio | 带图的稿子 | 图片优先，留白多 |
| 练习册 worksheet | 题目、练习 | 行距大，留答题空间 |
| 长文集 longform | 长篇连载 | 行距最松，字号偏大 |

模板决定的是版式倾向，具体字号、页边距、页眉页脚都能在「全文设置」里改。

## 「导出后核对」怎么读

导出完会弹一张表，最上面一行是结论：

```
成品 8 页 · 排版 8 页 · 已核实 45 · 缺失 0 · 页码不符 0 · 需人工 3
```

- **已核实**：这一段文字在 PDF 里逐字找到了。
- **缺失**：源文里有、成品里找不到——**这是唯一需要立刻处理的**。点一行能跳到对应页面。
- **页码不符**：目录写的页码和实际页码对不上。
- **需人工**：图片、公式、图表按图片渲染，没法用文字比对，得自己扫一眼。**正常情况下就是 3 条**（一张图 + 两处公式/图表），不是问题。

结论显示「通过」= 缺失和页码不符都是 0。

## 这轮修掉的问题（0.1.0）

这些都是「成品看着正常、其实少了内容」的隐形故障，逐条列出来备查：

1. **窗口不可见时排版死锁**
   之前排版要等一个动画帧才继续。Obsidian 最小化、被完全遮挡、或者屏幕锁了的时候，这个帧永远不会来，于是排版永久卡住（顶栏一直转、按钮全失效）。
   现在等帧带 120ms 超时兜底，另有 45 秒看门狗：真卡住会主动放开并提示「排版超时，已中断」。

2. **章首页不换页 → 溢出、页码全错、少一页**
   带大号码的章首页是「整页版式」（高度 100%）。它被接在目录页后面往下排，从半页处再占满一整页，必然顶出页底被裁掉。
   现在章首页一定从新的一页开始；关闭「章首页独占一页」时自动降级成小标题，不再撑破页面。

3. **导出撞上正在进行的排版**
   点「导出 PDF」时如果上一轮排版还没跑完（或者刚切换模板），导出的会是上一版、甚至排到一半的页面。
   现在导出和核对都会先等排版彻底停下（含补排那一轮）再动手。

4. **首排量错高度**
   图片、公式、图表是异步落地的。第一次量的时候它们可能还没有尺寸，于是「看着放得下」，等真正打印时又长出来，把内容顶出页面。
   现在：排之前先等媒体就位；排完再逐页检查有没有溢出，溢出就补排一轮（最多 3 轮）。

5. **排版进行中再改设置会丢**
   之前排版跑着的时候再点一次排版会被直接丢弃，界面停在旧结果上。现在会记账，等这轮结束立刻补排。

## 已知限制

- **公式与图表按图片渲染**：PDF 里的公式是图形，文字比对抓不到，所以固定列进「需人工」。生成教材、讲义这类公式多的稿子时，请自己翻一遍。
- **样张截图需要窗口可见**：截图走 Chromium 的合成层，Obsidian 处于最小化、被完全遮挡或屏幕锁定时拍不出图（脚本会直接报错退出，而不是卡住）。要更新本目录外的样张图，请在窗口可见时再跑。
- **只在桌面端**：导出走 Electron 的打印接口，移动端没有。

## 排障

| 现象 | 怎么处理 |
| --- | --- |
| 第三方插件里看不到它 | 文件夹名必须是 `notes-to-book`，且 `main.js` 要在这一层 |
| 提示「N 篇笔记找不到」 | 笔记被改名或移动了。右侧清单里点那篇的「修」，重新指定 |
| 提示「排版超时，已中断」 | 再点一次排版。连续出现请把窗口切到前台（屏幕锁定/最小化会让渲染变慢） |
| 导出的 PDF 和预览不一样 | 正常不应该发生。请保留那次导出的文件，并把「核对」结果发出来 |
| 想快速确认核对是否有效 | 命令面板搜「自测：导出时故意漏掉跨页表末行」，它会在导出时删掉最后一行，核对应该报缺失 |
