# overlays：三个可选钩子

这个目录可以整个不要。缺文件、缺目录、JSON 写坏，脚本都只打一行提示然后走默认排版，不会中断。

```
overlays/
├── patches/<科目>.json   内容订正表：改错字、改口径，不动源笔记
├── figures.json          字符图 → 矢量插图
└── mermaid.json          mermaid 块 → 指定字符图
```

---

## patches/<科目>.json

一个 JSON 数组，每项 `[正则, 替换文本]`，按顺序 `re.sub` 到正文上。

```json
[
  ["pH\\s*=\\s*7\\s*时", "pH = 7 时"],
  ["浓硫酸可以干燥\\s*NH₃", "浓硫酸不能干燥 NH₃"]
]
```

用它有三个理由：

1. 源笔记可能是从别处导出的，不想动它的历史；
2. 同一个错在多课重复出现，一处改一处漏；
3. 想保留「原稿 → 修正」的痕迹，而不是直接覆盖。

**注意**：它作用于全书正文，正则写宽了会误伤。每条都该满足「在本书正文里只命中想改的那一处」。
改完必须跑 `audit_books.py`，看 C8（化学式）和 C10（公式残留）有没有新告警。

正则里的 `\` 在 JSON 里要写成 `\\`。

## figures.json

把某一段字符图换成矢量图。

```json
{
  "化学": [
    {
      "lesson": "01 物质的分类",
      "anchor": "```text",
      "kind": "tree",
      "spec": {"root": "物质", "children": ["纯净物", "混合物"]},
      "caption": "图 1-1　物质的分类"
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `科目` | 顶层键，必须与笔记库的科目目录同名 |
| `lesson` | 课时文件名，不含 `.md` |
| `anchor` | 代码块的前若干字符；命中哪块就换哪块 |
| `kind` | 图元名，交给 `figlib.render(kind, spec, width)` |
| `spec` | 图元参数 |
| `caption` | 图题，排在图下，可省 |
| `drop` | 可选，字符串数组。矢量图排上后，这些文本块不再印（用于去掉重复的字符图） |

`figlib` **不在本仓库**。它是这套脚本原来配的一个小绘图模块，负责把 `kind` 和 `spec` 渲染成
reportlab 的 flowable。缺了会打印「未装 figlib，overlays/figures.json 里的矢量图跳过」并继续，
正文照常出字符图。

想用这个钩子，自己写一个 `figlib.py`，暴露：

```python

    """返回 reportlab flowable，或 None 表示画不出来。"""
```

## mermaid.json

笔记里写了 ` ```mermaid ` 块时，默认会从源码抽节点排成箭头链：

```
  溶液 ─▶ 胶体
  胶体 ─▶ 浊液
```

想要更像样的排法，就在这里指定替代文本（按课时覆盖）：

```json
{
  "化学": {
    "02 分散系与胶体": [
      "按分散质粒径分类",
      "├─ 小于 1 nm：溶液",
      "├─ 1–100 nm：胶体",
      "└─ 大于 100 nm：浊液"
    ]
  }
}
```

给的是行数组，等价于一段字符图。box-drawing 字符（`├ ─ │ └`）会被等宽排版对齐。

说实话，直接在手写笔记里用 ` ```text ` 写字符图，比配这张表更省事。这个钩子主要是给
「已经写了一堆 mermaid、又不想逐块改」的情况兜底。
