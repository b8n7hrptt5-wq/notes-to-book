# notes-to-book

把一棵 Obsidian 笔记树编译成可打印的 A4 讲义。

![python](https://img.shields.io/badge/python-3.9%2B-3776ab)
![reportlab](https://img.shields.io/badge/reportlab-4.0%2B-d97706)
![license](https://img.shields.io/badge/license-MIT-2ea043)

写笔记是碎片化的：一个知识点一个文件，靠双链和目录串起来。但复习时想拿着一本纸书翻。
这个脚本做的是中间那段——读你的 markdown，按固定体例排版，生成带封面、目录、页码、索引的 A4 书。

一次配好体例，之后改一条笔记，页码、目录、索引全部自动跟着变。这是它唯一的价值，也是它唯一的理由。

---

## 生成出来是什么样

每册一个 PDF，七个部分：

| 页 | 内容 |
|---|---|
| 封面 | 科目名、册名、教材版本、课时数、知识点数 |
| 这本怎么用 | 一页纸的阅读法（怎么读九板块、复习节奏怎么排） |
| 目录 | 章 / 单元 / 课时三级，点线连接，页码与正文一致 |
| 凡例 | 版式约定与符号说明 |
| 正文 | 章导览页 + 每课时九板块 |
| 附录一 | 知识点速查，按学册与章节顺序，一句定义 + 判断要点 |
| 附录二 | 知识定位，按拼音排序，词条 → 首次出现页 |

正文的九个板块顺序固定，缺哪个就少哪个，不会补空标题：

```
本节要点 → 知识点梳理 → 图示理解 → 判断与解题流程 → 高考考向与解题技巧
→ 必背速查 → 易错辨析 → 记忆与复习 → 练习（附参考答案）
```

## 快速开始

```bash
git clone https://github.com/<your-name>/notes-to-book.git
cd notes-to-book
pip install -r requirements.txt

# 用自带的示例库跑一遍，约 20 秒，出一本 14 页的小书
python3 bookgen.py 化学 --vault examples/demo --outdir out
open out/化学/化学·必修第一册.pdf

# 检查成品
python3 audit_books.py --pdf "out/化学/化学·必修第一册.pdf"
```

示例库是一本真的化学小册：两课、两个知识点，九个板块齐全，能完整跑通封面到附录的全部流程。
懒得跑的话，`examples/sample-output.pdf` 就是它的产物，14 页，可以直接翻。

换成自己的笔记库：

```bash
python3 bookgen.py --vault ~/Documents/我的笔记 --outdir ~/Desktop/打印本
python3 bookgen.py 化学 物理 --vault ~/Documents/我的笔记      # 只做两科
python3 bookgen.py 化学 --only "必修第一册" --vault ...        # 只做一册
```

不写 `--vault` 时读环境变量 `NOTES_VAULT`，再缺省为 `~/notes`。

## 输入格式

### 目录层级即书的结构

```
我的笔记/
└── 化学/                          ← 科目，一本书一个目录
    └── 必修第一册/                 ← 册，一个 PDF 一册
        └── 专题01 物质的分类及计量/  ← 章
            └── 01 第一单元 物质及其反应的分类/   ← 单元
                ├── 01 物质的分类.md              ← 课时，一个 md 一课
                ├── 02 分散系与胶体.md
                └── 知识点/                        ← 词条，进附录
                    ├── 酸性氧化物.md
                    └── 胶体.md
```

没有「单元」这一层的也可以：课时 md 直接放在章目录下，脚本会自动降级成两级目录。
文件名开头的序号（`01`、`02`）会被剥掉，只用作排序，不进标题。

### 课时的 frontmatter

```yaml
---
科目: 化学
学册: 必修第一册
章节: 专题01 物质的分类及计量
单元: 第一单元 物质及其反应的分类
知识点: 物质的分类
日期: 2026-11-25
tags: [化学, 物质分类, 苏教版必修一]
考频: 常考
来源: 苏教版（2019）必修第一册专题1第一单元
---
```

只有 `学册`、`章节` 用于成书时的归属校验，其余字段保持你自己的习惯即可。

### 课时正文

导语写在第一个 callout 之前，用一个 `>` 引用块表示：

```markdown
# 物质的分类

> 分类不是给物质贴标签，而是先定标准、再看它落在哪一格。
```

九个板块用 Obsidian 的 callout 标记，`[!类型]` 后面的文字就是这个板块的标题：

| callout | 板块 | 内容 |
|---|---|---|
| `[!summary]` | 本节要点 | 三到五条结论句 |
| `[!note]` | 知识点梳理 | 正文主体：定义、分类、表格、推导 |
| `[!abstract]` | 图示理解 | 一张结构图或流程图 |
| `[!example]` | 判断与解题流程 | 一类题的判断顺序 |
| `[!important]` | 高考考向与解题技巧 | 考法、设问、踩分点 |
| `[!important]` | 必背速查 | 只留结论，方便抽查 |
| `[!warning]` | 易错辨析 | 混淆点与典型错答 |
| `[!tip]` | 记忆与复习 | 记忆方法与复习节奏 |
| `[!question]` | 练习 | 题 + `**参考答案**` |

`[!important]` 出现两次，靠标题文字区分（`高考考向与解题技巧` 与 `必背速查`），顺序不乱就行。

练习的写法：

```markdown
> [!question] 练习
>
> 1. 下列物质中属于纯净物的是（　　）
>    A. 盐酸　B. 液氯　C. 漂白粉　D. 空气
> 2. 判断正误：金属氧化物一定是碱性氧化物。
>
> **参考答案**
>
> 1. B。液氯是液态的 Cl₂，只含一种物质。
> 2. 错误。Al₂O₃ 是金属氧化物，但属两性氧化物。
```

答案按题号对齐，缺号的按顺序补位。第一条 `。` 之前的部分排成加粗结论，之后排成解析段。
题数与答案条数不一致时，`audit_books.py` 的 C5 会报出来。

### 板块里能用的 markdown

| 写法 | 效果 |
|---|---|
| `**粗体**` | 加粗 |
| `==高亮==` | 加底色 |
| `$公式$` | 转成矢量排版（不是图片） |
| `[[双链]]` | 排成正文里的篇目提示，书末不重复列 |
| `### 小标题` | 板块内加粗小标题 |
| `\| 表 \| 格 \|` | 带斑马纹的表格，长表跨页重复表头 |
| 普通代码块 | 按字符图排，等宽字型保留缩进与连接符（` ├─ └─ │` 会对齐） |
| mermaid 代码块 | 抽节点与连线排成箭头链；想出版式好看的图，直接写字符图更省事 |
| `![[图片.png]]` | 插图，按版心宽度等比缩放 |

### 复习卡（生成 Anki 卡片的原料）

正文末尾加一节，一条一行，`问题 :: 答案`：

```markdown
## 复习卡（Spaced Repetition）

- 树状分类法的核心要求是什么 :: 每一级只用一个标准，逐级划分，不交叉不遗漏
- Al₂O₃ 属于哪一类氧化物 :: 两性氧化物，既能与酸反应又能与碱反应
```

排进书末的「自测」区块，只把问题印在书上，答案另起一段。这一节本身不会印成正文段落。

### 词条（附录的来源）

`单元/知识点/词条名.md`，两个固定小节：

```markdown
---
科目: 化学
学册: 必修第一册
专题: 专题01 物质的分类及计量
课时: 01 物质的分类
---

# 酸性氧化物

## 一句话定义

能与碱反应生成盐和水的氧化物。

## 讲解

==酸性氧化物==的判断依据是反应事实，不是元素种类……
```

`课时` 字段必须能在本册找到同名课时，否则索引定位会退回全册搜索并在报告里记一次失败。

## 命令行

```
python3 bookgen.py [科目 ...] [--vault DIR] [--outdir DIR] [--only 册名] [--sample]

  科目          留空则处理笔记库下的全部科目
  --vault      笔记库根目录（默认 $NOTES_VAULT 或 ~/notes）
  --outdir     成品输出目录（默认 $NOTES_OUT 或 ~/Desktop/打印本）
  --only       只做某一册，写册名全称
  --sample     同时导出七页校对样张 PNG
```

科目名不必是语文数学这些固定值，任何目录名都行；不认识的颜色会退回中性灰，教材版本退回「人教版」。

## 它是怎么工作的

排版不是一次算完的。目录页码要指向正文真实页，索引要指向词条真实出现页，而这两件事只有排完才知道。
所以是**排 → 量 → 再排**的循环：

```
读 markdown ──▶ 切九板块 ──▶ 排一遍 PDF
                                  │
                   ┌──────────────┴──────────────┐
                   ▼                             ▼
            量目录标题落在第几页          量词条首次出现页
                   │                             │
                   └──────────────┬──────────────┘
                                  ▼
                       带着真实页码重排（最多 4 轮）
                                  │
                                  ▼
                        尾页只剩一两行的课时收紧行距
```

最后一步是「尾页紧排」：某课的最后一页只有两三行时，把这一课的行距压到 95.5%、段距压到 60%，
让它缩回上一页，省掉一张几乎空白的纸。压不下去就保持原样，不硬挤。

## 版式规格

| 项 | 值 |
|---|---|
| 纸张 | A4，单面或双面均可 |
| 页边距 | 上 64 / 下 62 / 左右 72 pt |
| 版心 | 451 × 716 pt |
| 正文字号 | 10.8 pt，行距 1.62 倍 |
| 字体 | 正文宋体，标题黑体，字符图等宽，公式用 Unicode 数学符号 |
| 页码 | 正文起算，前置页不印 |
| 页眉 | 左：科目·册名；右：章名 |

## overlays：三个可选的补丁钩子

`overlays/` 不入库也行，缺了就全走默认。三份 JSON 各管一件事：

**`patches/<科目>.json`** —— 内容订正表，避免为了改一个错字去改源笔记：

```json
[
  ["原文正则", "替换文本"],
  ["pH\\s*=\\s*7\\s*时", "pH = 7 时"]
]
```

在行内转换时按顺序 `re.sub` 到正文上。写错会污染全书，改完务必跑一遍 `audit_books.py`。
字段说明与示例见 `overlays/README.md`。

**`figures.json`** —— 把字符图换成矢量插图：

```json
{
  "化学": [
    {"lesson": "01 物质的分类", "anchor": "```text", "kind": "tree", "spec": {...}, "caption": "图 1-1"}
  ]
}
```

`anchor` 命中哪段文本，那一段就换成 `figlib.render()` 画的图。`figlib` 是本仓库**未包含**的可选模块，
缺了会打印一行提示并跳过，正文照常出字符图。

**`mermaid.json`** —— 手工指定 mermaid 块的替代排版：

```json
{"化学": {"01 物质的分类": ["物质", "├─ 纯净物", "└─ 混合物"]}}
```

没有它时按 mermaid 源码抽节点，排成 `A ─▶ B` 的箭头链。

## 字体

默认按平台顺序找系统里的中文字体，找到就用：

| 用途 | macOS | Linux | Windows |
|---|---|---|---|
| 正文宋体 | Songti.ttc (face 6) | Noto Serif CJK / 文鼎 | simsun.ttc |
| 标题黑体 | STHeiti Medium.ttc | Noto Sans CJK | msyh.ttc |
| 等宽 | Menlo.ttc | DejaVu Sans Mono | consola.ttf |

想指定自己的字体，用环境变量，值可以是 `路径` 或 `路径:face序号`：

```bash
export NOTES_FONT_SONG="/usr/share/fonts/truetype/思源宋体.ttc:0"
export NOTES_FONT_HEI="/usr/share/fonts/truetype/思源黑体.ttc:0"
```

缺正文或标题字体时会直接停下并告诉你缺哪个，不静默降级——中文字体错了整本书都是方框，不如早报错。

字体文件本身不入库，只引用路径。

## audit_books.py：反向验收

生成完的 PDF 反向检查一遍。它不读 markdown，只读成品，所以能抓到排版过程引入的问题。

```bash
python3 audit_books.py --pdf "out/化学/化学·必修第一册.pdf"
python3 audit_books.py --pdf ... --out report.json          # 落 JSON
python3 audit_books.py --pdf ... --render 3,8,12-14 --dir png # 渲染指定页
```

十三项检查，`C7 C8 C10 C12 C13` 是硬性项，命中即 FAIL：

| 代号 | 检查 | 判据 |
|---|---|---|
| C1 | 页数与页码 | 印页码从 1 连续到最后，无跳号重号 |
| C2 | 目录条目 | 每条目录页码 = 该标题实际印刷页 |
| C3 | 只有标题的页 | 非封面页正文 < 120 字 |
| C4 | 页尾留白 | 单页底部留白 > 20%（排除课时末页、章导览、附录、前置页） |
| C5 | 题数 = 答案条数 | 每课时练习的题数与答案条数一致 |
| C6 | 题号连续 | 练习与答案都从 1 连续编号，无圆点套数字 |
| C7 | 图块无壳残留 | 无 mermaid 块、代码围栏残留 |
| C8 | 无字符拼化学式 | 无 `H2SO4` 这类写法，上下标已排 |
| C9 | 章标题位置 | 章标题在页面顶部 1/5 区域 |
| C10 | 公式残留 | 无 `$…$`、`\(…\)`、裸 LaTeX 命令 |
| C11 | 索引指向 | 知识定位每条指向词条真实出现页 |
| C12 | 死链残留 | 无 `[[ ]]`、`![[` 残留 |
| C13 | 单册页数上限 | 默认 400 页，超了说明分册逻辑有问题 |

示例库跑出来十三项全绿，可以当回归基线：

```
C1 OK 14页，页码 1-10 连续          C8  OK 无字符拼化学式
C2 OK 目录 6 条 / 命中 6            C9  OK 章标题均在页面顶部 1/5 区域
C3 OK 无正文 < 120 字的页           C10 OK 无 $…$ / \(…\) 残留
C4 OK 无异常留白页                  C11 OK 知识定位 2 条 / 命中 2
C5 OK 2 个课时题数=答案数           C12 OK 无 [[ ]] 残留
C6 OK 题号连续 1..n                 C13 OK 14页 ≤ 400
C7 OK 无 mermaid/代码壳残留         PASS
```

## 已知限制

- **中文避头尾只做了行首禁则**。reportlab 的 CJK 断行会让 `。，）` 这类标点不在行首悬挂，但不会阻止一行以 `（` 结尾。要彻底解决得替换断行器，暂时没做。
- **mermaid 只排字符兜底图**，不做真布局。想要好看的结构图，直接在笔记里写字符图（` ```text ` 代码块），效果比兜底好得多。
- **`figlib` 未开源**，`figures.json` 里的 `kind` 是新图元，需要自己实现 `render(kind, spec, width)`。
- **C4 的留白是取舍**。练习题与答案按实测高度整块挪页，宁可让上一页空 20%～30%，也不让答案单独占一页。想反过来，把 `bookgen.py` 里 `AVH * 0.62` 调小。
- **只处理单列正文**，没有双栏、没有脚注、没有浮动图表。
